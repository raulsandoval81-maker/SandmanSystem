How this page works Instructions
Purpose

Manage login access for an athlete who already exists in Sandman.

What you do here

Search by Athlete ID or name, review current access, and issue Direct Athlete Access when approved.

Access options

Issue Hybrid access while keeping the Parent linked, issue Self-Managed access when appropriate, or transition Hybrid access to Self Managed.

Touch limit

This page manages access only. It does not create enrollment, change membership or pricing, change rank or XP, alter athlete progression, or replace the athlete record.
