Emergency Protocols

Safety First

Stop · Secure · Assess · Call · Contact · Document

Medical Emergency

  1. Stop all activity.
  2. Assign coach to athlete.
  3. Call 911 if required.
  4. Retrieve emergency contact.
  5. Contact parent/guardian.
  6. Document incident.

Head / Neck Injury

  1. Do not move athlete.
  2. Stabilize area.
  3. Assess responsiveness.
  4. Call EMS if needed.
  5. Notify parent immediately.

Bleeding

  1. Stop activity.
  2. Apply pressure.
  3. Use protective gloves.
  4. Clean affected area.
  5. Follow return-to-play rules.

Asthma Attack

  1. Remove athlete from activity.
  2. Assist with inhaler if available.
  3. Monitor breathing.
  4. Call EMS if symptoms escalate.
  5. Contact parent.

Allergic Reaction

  1. Identify symptoms.
  2. Use emergency medication if prescribed.
  3. Call 911 for severe reaction.
  4. Contact parent immediately.
  5. Document event.

Missing Athlete

  1. Stop activity.
  2. Secure facility.
  3. Account for all athletes.
  4. Search designated areas.
  5. Contact parent.
  6. Call authorities if needed.

Fire / Evacuation

  1. Stop activity.
  2. Evacuate immediately.
  3. Use designated exits.
  4. Account for all athletes.
  5. Call emergency services.

Facility Lockdown

  1. Secure all entrances.
  2. Move athletes to safe area.
  3. Remain quiet.
  4. Follow law enforcement instructions.
  5. Contact parents when safe.
