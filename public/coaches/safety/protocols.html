Emergency Protocols

Stop · Secure · Assess · Call · Contact · Document

Medical Emergency

  1. Stop activity.
  2. Clear space.
  3. Call 911 if serious.
  4. Contact parent.
  5. Document after stable.

Head / Neck Injury

  1. Do not move athlete.
  2. Stop room.
  3. Call 911 if needed.
  4. Notify parent.
  5. No return same day.

Bleeding

  1. Stop activity.
  2. Use gloves/barrier.
  3. Apply pressure.
  4. Clean mat area.
  5. Return only when safe.

Missing Athlete

  1. Stop transitions.
  2. Check exits/restrooms.
  3. Notify parent.
  4. Escalate if not located fast.

Fire / Evacuation

  1. Stop activity.
  2. Exit calmly.
  3. Account for athletes.
  4. Call emergency services.
