Skill 3 — Setup System

Tree: Tactical Boxing

Tier: Youth T4 — Warrior

Structure (A/B/C)

A — Show The First Look

B — Create The Reaction

C — Attack The Opening

Coaching Cues

  • “Make them react”
  • “Show one thing, do another”
  • “The setup creates the opening”

Common Mistakes

  • Attacking without creating a reaction
  • Repeating the same setup
  • Telegraphing the real attack

Drill Ideas

  • Feint-and-jab drill
  • Jab-to-body setup
  • Partner reaction setup drill

Progression

  • Connect setups to advanced attacks
