Skill 6 — Hook Counter

Tree: Counter Boxing

Tier: Youth T2 — Contender

Structure (A/B/C)

A — Defend The Attack

B — Set The Feet

C — Return With The Hook

Coaching Cues

  • “Block, then turn”
  • “Short hook”
  • “Opposite hand stays home”

Common Mistakes

  • Swinging the hook too wide
  • Countering before balance returns
  • Dropping the opposite hand

Drill Ideas

  • Block-and-hook drill
  • Slip-and-hook drill
  • Partner glove target

Progression

  • Connect hook counters to angle exits
