Practice Operations

Move through the coaching day in order. Build the session, run the room, check athletes in for attendance, review and finalize attendance, then complete the day’s XP work.

1

Build Session

Choose the room, discipline, rank, week, and session shell.

2

Run Practice

Build the practice in Clipboard and launch the active practice.

3

Check In / Attendance

Load the active practice and record attendance as athletes check in.

4

Review & Finalize Attendance

Verify check-ins, correct attendance if needed, then lock and close the practice.

5

Daily XP

Complete the verified coach-side XP work after attendance is final.
