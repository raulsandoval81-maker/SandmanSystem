`issueproposalclientreview-00003-ler`, Node 22. Its uploaded package main was
`staging-release-entry.cjs`, source generation `1793483602816623` in
`gs://gcf-v2-sources-991554514268-us-central1/issueProposalClientReview/function-source.zip`.
