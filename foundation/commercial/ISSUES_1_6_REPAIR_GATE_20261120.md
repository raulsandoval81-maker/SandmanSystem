# Commercial Issues 1–6 — implementation and release gate

Status: **PARTIAL IMPLEMENTATION; NO RELEASE AUTHORIZATION.** This branch is a pre-Sprint-7 correction, not confirmation that all six issues are complete.

## Decisions and verified source status

1. **Progression** — Commercial already encodes Road2Champion (800/1600/2400/2800/3200) and Path2Legend (1000/1600/2400/2800/3000), each totaling 10,800. This branch adds regression protection against redefining ranks or assigning a locally injected curriculum whose ranks violate the standard. **Open:** reconcile conflicting Academy Path2Legend source constants through separate, guarded Academy review; age-14 transition/Champion exception, and promotion gate evidence end-to-end.
2. **Decay and recovery** — Academy PR #749 merged but its staging/build/production verification is unconfirmed. Commercial `applyDecay` and `recordRecoveryCandidate` remain explicitly fail-closed pending attendance/full-practice proof, verified stripe floor/history, event replay, and recovery-state persistence. Never activate decay based on caller-supplied reason alone.
3. **Curriculum** — Active Commercial disciplines explicitly allow only wrestling, boxing, and Muay Thai. BJJ is not active; the only allowed future placeholder language is **SUBMISSION GRAPPLING — COMING SOON** (UI copy to implement separately). This branch blocks unapproved discipline definitions and assignments, empty or all-optional skill catalogs, and noncanonical ranks while allowing coach-added concept/technique entries. **Open:** design and verify separately versioned Sandman core vs. coach-specific curriculum layers and safe uploads, with non-removable core conceptual competency requirements.
4. **Authentication** — Current identity issuer is **test-only**. Agreed: hybrid owner registration followed by Sandman Systems activation approval; Organization Admins and scoped Location Managers invite staff; Admins/Managers issue parent and athlete invitations; password recovery is self-service or Management-initiated without password disclosure. **Open:** production identity provider, email proof, durable invite expiration/replay protections, approval state machine, account recovery, revoked sessions, location scopes and audit tests. Must not expose test identity minting.
5. **Persistence** — Current Commercial store is in-memory / local JSON, **not production-ready**. Approved target: independent PostgreSQL with tenant-scoped constraints, transactional append-only XP and promotion lineage, and verified isolation. This is the persistence implementation dependency in Sprint 7, not yet implemented.
6. **Family privacy, transfers, and promotion** — Minors require guardian consent plus receiving Management acceptance; adults consent for themselves plus receiving acceptance. Prior gym is notified, not a veto holder. Verified rank, stripes, active/unspent XP, and lifetime achievement history follow athlete; private previous-gym coach notes never transfer, and training history is shared only with separate authorization. Transfer may not demote based on local stylistic differences; Sandman core concepts are the baseline, while the receiving coach adapts training. Rare correction/demotion requires independent, documented standards review; no unilateral coaching downgrade. **Open:** globally portable athlete identity, cross-tenant consent/reconciliation protocol, event lineage, private-record filtering, redaction, audit trail, rollback/replay/duplicate prevention, and actual transfer tests. Do **not** copy records across organization boundaries in the current JSON adapter.
