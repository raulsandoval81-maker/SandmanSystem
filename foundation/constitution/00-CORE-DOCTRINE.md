# Sandman Core Doctrine

**Status:** LOCKED unless explicitly revised.

This document defines the highest-level operating doctrine of Sandman System.

If a proposed feature, workflow, role, page, or automation conflicts with this document, the doctrine must be reviewed before implementation changes are made.

---

# 1. Sandman Purpose

Sandman exists to build stronger people through:

**Combat • Strength • Honor**

The platform should support athlete development, coaching quality, family trust, operational clarity, and long-term organizational growth.

Software exists to support the mission.

The mission does not exist to support the software.

---
